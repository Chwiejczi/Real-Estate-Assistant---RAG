#Real Estate Assistant project: Combined RAG and machine learning approach to help user realize the potential price of estate located in each district in Warsaw 


#Project's parts are: Machine learning part- it will calculate possible price of estate, RAG part- it will work on given files to make conclusions about estate situation. By combining these two approaches, the applications delivers more comprehensive and informative results than either component could provide on its own. Project will be also equipped with data-entry AI agent, it will provide better communication with user and it will validate entered data.

#The project is containerized using Docker. All required technologies and dependencies are specified in the requirements.txt file.
